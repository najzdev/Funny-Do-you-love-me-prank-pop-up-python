# 💘 Do You Love Me?

A cute little prank app that asks one very important question:

> **Do you love me Niama? ❤️**

Choose carefully... the app may not accept **No**. 😄

## ✨ Features

- 💖 Playful love question
- 🌹 Funny date request
- 🏃 Dodging **No** button
- 💕 Falling hearts on the final screen
- 🌐 Standalone browser version
- 🖥️ Desktop executable support

## 🌐 Open the Web Version

Open [index.html](./index.html) in any modern browser.

No installation or internet connection is required.

## 🐧 Build on Fedora Linux

Make the build script executable:

```bash
chmod +x build_linux.sh
```

Build the app:

```bash
./build_linux.sh
```

Run it:

```bash
./dist/DoYouLoveMe
```

The Linux executable is created in `dist/DoYouLoveMe`.

## 🪟 Build on Windows

Double-click [build_exe.bat](./build_exe.bat), or run it from Command Prompt:

```bat
build_exe.bat
```

The Windows executable is created at:

```text
dist\DoYouLoveMe.exe
```

## 🐍 Run from Python

Install Python 3, then run:

```bash
python3 meow.py
```

The app uses Tkinter, which is included with most Python installations.
